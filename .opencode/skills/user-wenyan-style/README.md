# WenyanNature 编码风格模仿 Skill

## 概述

这是一个根据 **WenyanNature** 项目（文言编程语言Minecraft Mod）提炼的编码风格模仿 Skill。通过对项目全量代码（379个Java文件，7个Python文件）进行蒸馏分析，捕捉了作者的稳定编码习惯。

## 来源样本

- **核心基线**：`judou/`（文言编译器，117文件） - 高置信度单人项目
- **注解处理器**：`language_processor/`（8文件） - 风格一致
- **业务代码**：`src/`（Minecraft Mod，254文件） - 存在小部分多人协作可能，但风格与基线高度一致
- **测试代码**：47个测试文件（JUnit 5）
- **脚本工具**：7个Python生成脚本

## 提炼方法

1. **广度扫描**：全量读取所有Java文件，建立覆盖地图
2. **深度分析**：按模块（编译器、GUI、网络、测试）抽样深读
3. **三重验证**：复现性（跨文件）、特异性（区分性）、可执行性（可转规则）
4. **来源归因**：区分本人手写、AI辅助、协作者（本项目未发现明显污染）

## 核心发现

### 高置信度 Java 习惯
- **接口 I 前缀**：`IWenyanValue`, `IWenyanFunction`
- **类名领域前缀**：`WenyanInteger`, `WenyanCompiler`
- **类型偏好**：`record`（值对象），`enum`（工具类/单例）
- **控制流**：`switch`表达式（Java 17+）
- **错误处理**：自定义异常层次，显式`throws`
- **注解使用**：JetBrains `@NotNull`/`@Nullable`，Lombok（GUI/DTO层）
- **测试组织**：JUnit 5参数化测试，继承助手类
- **包结构**：按功能分层（非严格技术分层）

### 命名语言质量
- 标准英文命名，无拼音/中文混用
- 局部变量语义清晰（`value`, `bytecode`, `environment`）

### 注释策略
- 核心库注释密度高（5.5行/文件）
- 业务代码注释稀疏（2.2行/文件）
- Javadoc风格为主，行内注释仅用于TODO/HACK

## 如何使用

### 1. 加载 Skill
```yaml
# 在opencode对话中
使用技能：imitate-wenyan-style
```

### 2. 提供上下文
- 目标模块的近邻文件（最重要）
- 要实现的函数/类描述
- 目标语言（Java/Python）

### 3. 生成代码
Skill将按以下优先级生成代码：
1. 模仿近邻文件的现有写法
2. 应用Java高置信度规则
3. 参考代表性片段微习惯
4. 保守补全（社区常规）

## 适用场景

### ✅ 适合
- 为WenyanNature项目添加新功能
- 编写类似技术栈的代码（Java 17+、编译器、Minecraft Mod）
- 需要保持与现有代码库一致的风格
- 用户明确要求"按我的风格写"

### ❌ 不适合
- 非Java项目（Python样本不足）
- 完全不同领域的技术栈（如前端React）
- 需要完全创新、无现有模式可循的场景

## 限制与边界

### 样本边界
- **Java**：样本充足（379文件），高置信度
- **Python**：样本不足（7文件），不提炼专属习惯
- **其他语言**：无样本

### 技术边界
- **Java版本**：假设Java 17+（record/switch表达式）
- **框架依赖**：部分习惯与Minecraft NeoForge框架相关
- **领域特定**：`Wenyan`前缀是项目特定

### 协作边界
- 未发现明显AI强辅助或协作者污染
- 风格一致性高，可视为单人主笔或紧密协作

## 文件说明

- `SKILL.md`：技能主体，包含模仿规则和决策流程
- `references/style-profile.md`：完整代码风格报告（详细分析）
- `references/representative-snippets.md`：代表性代码片段（直接模仿）
- `evals/evals.json`：验证用例（测试技能效果）

## 验证

包含3组验证用例：
1. 给定现有样本，能否产出正确的风格报告
2. 给定风格报告，能否按Java风格模仿写代码  
3. 面对边界场景，能否维持保守补全策略

## 更新与维护

如需更新此Skill（添加新样本、修正结论）：
1. 重新运行全量蒸馏分析
2. 更新style-profile.md和representative-snippets.md
3. 同步更新SKILL.md中的规则
4. 更新验证用例
