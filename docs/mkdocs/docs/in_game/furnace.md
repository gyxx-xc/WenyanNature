# 炉烘有天（暂定）

用于**烧炼**的高级炉子，可以通过两种不同的进度控制方式烧炼物品。

## 用途

逻辑炉是一种特殊的烧炼装置，提供了两种进度控制方式：
- **逐次增加**：每次增加一点进度，无需燃料，适合小批量烧炼
- **倍数增长**：每次将当前进度翻倍，速度极快但需要精确控制

与普通炉子不同，逻辑炉允许你通过编程精确控制烧炼进度，实现高效的批量处理。

## 使用方法

### 基础设置

1. **放置逻辑炉**：将逻辑炉放置在合适的位置
2. **放入材料**：打开GUI，在上方输入槽放入需要烧炼的物品
3. **选择烧炼方式**：通过符咒调用相应的函数控制烧炼进度

### 进度控制函数

在符咒中调用以下函数来控制烧炼进度：

```
施「熔」。 // 逐次增加一点进度
施「倍熔」。 // 将当前进度翻倍
施「取熔」。 // 获取当前进度值
施「取熔最大」。 // 获取所需进度总值
```

- **「熔」**：逐次增加一点进度，当进度达到所需值时自动完成烧炼
- **「倍熔」**：将当前进度翻倍，速度极快但需要精确控制
  - 如果翻倍后进度**等于**所需值，正常完成烧炼
  - 如果翻倍后进度**超过**所需值，输入物品会被销毁
- **「取熔」**：获取当前进度值（0到所需值之间）
- **「取熔最大」**：获取烧炼所需的总进度值

### 烧炼机制

- **进度计算**：所需进度 = 物品烧炼时间 × 数量 × 随机缩减
  - 批量越大，缩减幅度越大，烧炼速度越快

## 注意事项

- 逻辑炉支持**熔炼、高炉烧炼、营火烹饪**三种配方类型
- 输入槽在上方，输出槽在下方，与普通炉子布局相同
- 倍数增长方式需要精确控制，进度超过所需值会导致物品被销毁
- 每次放入新物品或物品数量变化时，进度会重新计算
- 没有有效配方时，调用函数会报错

## 策略建议

1. **小批量处理**：使用逐次增加方式，安全可靠，无需担心物品销毁
2. **大批量加速**：使用倍数增长方式，结合进度监控实现高效烧炼
3. **进度监控**：定期调用「取熔」函数，确保倍数增长不会超过目标值
4. **批量优化**：一次放入多个物品可以享受随机缩减，加快烧炼速度
