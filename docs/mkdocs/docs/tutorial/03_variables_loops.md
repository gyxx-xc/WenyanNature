# 本节目标

学会让符咒显化文字之后，我们将继续学习两个常用的基本命令：**变量**与**循环**。

通过本节，你将学会：

* 如何让符咒记住一个数字。
* 如何让符咒重复执行同一段命令。
* 如何通过修改数字，改变符咒重复的次数。

---

# 理解变量与循环

## 1. 变量是什么？

> **变量，就是“给天地万物赋予名字”。**

变量就像一个贴了名字的宝箱。
宝箱里可以装数字、文字，也可以装其他事物。

当你想再次使用宝箱里的东西时，不需要重新写一遍，只需要唤出它的名字即可。

例如，我们可以准备一个数字 `3`，并给它起名叫「次數」。

---

## 2. 循环是什么？

> **循环，就是“让符咒重复做一件事”。**

如果想让符咒连续施展多次相同的命令，不必一遍遍重复书写。

只需要借用“循环”之律，告诉符咒要重复多少次，它便会照做。

---

# 编写进阶符咒

再次展开你的符咒，在其中写下下列内容：

```wenyan
吾有一數曰三。名之曰「次數」。
為是「次數」遍。
    書「「吾有一術」」。
云云。
```

这段符咒会显示三次：

```text
吾有一術
吾有一術
吾有一術
```

---

# 逐句理解

```wenyan
吾有一數曰三。名之曰「次數」。
```

这句话的意思是：准备一个数字 `3`，并把它命名为「次數」。

```wenyan
為是「次數」遍。
```

这句话的意思是：按照「次數」里的数字，重复执行接下来的命令。

```wenyan
    書「「吾有一術」」。
```

这是每一遍循环都会执行的内容。
因为「次數」是 `3`，所以这句话会被执行三次。

```wenyan
云云。
```

这表示循环到这里结束。

---

# 试着改一改

现在，把第一行里的数字改成其他数字：

```wenyan
吾有一數曰五。名之曰「次數」。
```

再次运行符咒，你会看到「吾有一術」显示五次。

这说明：
只要改变「次數」里的数字，就能改变符咒重复执行的次数。
