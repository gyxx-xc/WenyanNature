# 常见问题

新手看不懂报错很正常。很多问题不是你不会编程，而是符号、名字或摆放位置出了小差错。

## 先检查这些地方

- 中文引号是否成对。
- 变量名是否前后一致。
- 语句末尾是否写了 `。`。
- 循环最后是否有 `云云`。
- 模块是否放在符咒能连接到的位置。
- 输出是否接到了能显示的地方。

## 引号怎么分

变量名常写成：

```wenyan
「次數」
```

文字常写成：

```wenyan
「「吾有一術」」
```

简单说：一个名字用一层引号，一段要显示的文字常用两层引号。

## 报错大概是什么意思

如果报错里出现“不识”“未寻”，通常是有个名字没找到。

如果出现“参数不合”，通常是给某个命令的东西数量不对。

如果符咒没有显示结果，先检查螢幕石或输出位置。

## 新手口诀

一次只加一小步。

每加一步，就运行一次。看到结果正确，再继续写下一步。
