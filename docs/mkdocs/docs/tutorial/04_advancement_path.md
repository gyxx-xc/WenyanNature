# 拓展你的装备

《吾有一术》的进度树，不只是物品解锁路线，也是一条学习路线。

每获得更高阶的符咒、纸张与墨水，都代表你可以尝试新的能力。
不必一开始就理解全部内容，只要沿着进度树一步步前进即可。

---

# 进度学习路线

## 基础符：初识符咒

目标：完成 **吾有一术**，获得 **基础符**。

在这个阶段，你只需要学会最基础的操作：

* 如何运行符咒。
* 如何用 `書` 显示文字。
* 如何理解脚本会从上往下一句一句执行。

这一阶段的重点不是做出复杂功能，而是明白：
**符咒会按照你写下的顺序行动。**

---

## 一阶符：熟悉基本命令

目标：获得 **松竹纸**、**松清墨** 与 **一阶符**。

在这个阶段，你可以开始尝试更多基础命令：
* 用数字进行简单计算。
* 用文字模块处理文字。
* 用随机、列表等基础模块做小实验。
* 尝试修改变量，让符咒输出不同结果。

这一阶先不要急着大规模使用符咒，重点是熟悉“符咒如何使用”的感觉。

---

## 二阶符：与方块和物品交互

目标：获得 **云篆纸**、**朱砂墨** 与 **二阶符**。

从这一阶开始，符咒会逐渐接触 Minecraft 世界本身。

你将会学习：
* 用物品相关符咒读取或移动物品。
* 用方块相关符咒检查附近方块。
* 让符咒根据方块或物品情况做出反应。

这一阶段的重点是：
**让符咒不再只会说话，而是开始与世界交互。**

---

## 三阶符：与生物和实体交互

目标：获得 **星辉纸**、**星光墨** 与 **三阶符**。

在这个阶段，符咒将开始处理更复杂的对象。

你将会学习：
* 寻找附近的生物、掉落物或其他实体。
* 初步理解队列。
* 初步理解等待与延迟执行。

队列可以先理解成“排队窗口”：
先放进去的东西，会先被取出来。

这一阶段的重点是：
**让符咒学会处理多个目标，而不是只面对一个方块或一个物品。**

---

## 四阶符：具备强大功能的符咒

目标：获得 **霜华纸**、**月华墨** 与 **四阶符**。

这一阶段的符咒能力会明显增强，也更容易影响周围环境。

你将会学习：
* 读取更多世界信息。
* 使用更强的移动、推动、爆裂或阵眼类功能。
* 在运行符咒前，先判断它会不会破坏重要建筑。

建议先在测试世界练习，不要直接对主基地动手。

这一阶段的重点是：
**符咒越强，越需要谨慎。**

---

## 五阶符与六阶符：复杂的计算和极其强大的自动化

目标：获得 **凤羽纸**、**玄武墨** 与 **五阶符**；
之后继续获得 **龙鳞纸**、**冥土墨** 与 **六阶符**。

到了这个阶段，你已经可以尝试更完整的结构。

你将会学习：
* 设计稳定的大型符咒结构。
* 把变量、循环、判断与模块调用组合起来。
* 将多个符咒分工协作。


例如：
* 自动整理物品。
* 自动检测方块状态。
* 自动搬运或处理资源。

这一阶段的重点是：
**不只是会写符咒，而是能设计一套有用途的系统。**

---

#  循序渐进，方能以术入道

如果某一阶暂时看不懂，没有关系。

《吾有一术》的学习方式不是背完所有命令，而是：
1. 先照着教程运行。
2. 再试着修改一点点。
3. 看到结果变化。
4. 最后理解它为什么这样运行。

> 本模组中期、后期的扩展性和复杂性会显著高于普通模组，因此请尽情享受探索的乐趣！
